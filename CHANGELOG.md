# Changelog

## v1.1.0

- Heavy pages (big CSS, scroll animations or 400+ elements): the skill now offers to build on a local copy of the site first, when the companion `elementor-local-first` skill is installed. Light pages stay online with no question.
- Online heavy pages: test each fix in the browser first, then save the CSS in one call instead of resending the whole stylesheet.

## v1.0.0

- First GitHub version: skill files, install scripts, and an upload-ready zip build.
